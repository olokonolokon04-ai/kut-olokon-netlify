Учётные записи сотрудников

Операторы добавляют сотрудников и подтверждают записи других операторов. Создатель не может подтвердить свою запись. Администратор дополнительно управляет доступами и удалением записей.

Подтверждение вторым сотрудником

Пропуск можно распечатать только после подтверждения с другой учётной записи.

Сотрудник, который создал запись, не может подтвердить её сам. Другой сотрудник входит под своим логином с другого компьютера, проверяет данные и документы, затем нажимает «Подтвердить».
