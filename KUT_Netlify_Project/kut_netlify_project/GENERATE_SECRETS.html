КУТ — генератор секретных ключей

Откройте этот файл на своём компьютере. Секреты генерируются только в этом браузере и никуда не отправляются. Не отправляйте значения в чат и не добавляйте их в GitHub.

Скопируйте каждое значение в Netlify → Project configuration → Environment variables. После создания первого администратора удалите KUT_SETUP_TOKEN из Netlify и снова опубликуйте сайт. Два остальных ключа не меняйте: без прежнего ключа зашифрованные данные нельзя будет расшифровать.
